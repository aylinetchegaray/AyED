# Trabajo Práctico N° 1: Estructuras Lineales

Este módulo contiene la implementación de estructuras de datos lineales estáticas y dinámicas bajo el paradigma de la Programación Orientada a Objetos.

## Contenido del Práctico
*   **Listas Genéricas**: Implementación de `ListaGenerica` y su versión dinámica `ListaEnlazadaGenerica<T>` mediante nodos encadenados.
*   **Pilas Genéricas (`PilaGenerica<T>`)**: Estructura LIFO eficiente con operaciones de complejidad $O(1)$ basadas en inserciones al inicio de la lista.
*   **Colas Genéricas (`ColaGenerica<T>`)**: Estructura FIFO basada en inserciones al final y extracciones al inicio.
