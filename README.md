# Algoritmos y Estructuras de Datos (AyED)

Repositorio oficial de la cursada de **Algoritmos y Estructuras de Datos** de la **Licenciatura en Sistemas** en la Universidad Nacional de Río Negro (UNRN).

## Estructura del Repositorio

El repositorio se encuentra organizado por trabajos prácticos, implementando estructuras de datos dinámicas desarrolladas en Java (utilizando Maven):

*   **tp01/**: Implementación de listas genéricas (enlazadas), pilas y colas genéricas.
*   **tp02/**: Implementación y recorridos de Árboles Generales (n-arios), métricas estructurales y problemas de aplicación.

## Tecnologías Utilizadas
*   Java (JDK actual)
*   Apache Maven (Gestión de dependencias y estructura de proyectos)
*   JUnit / Clases de Test manuales para validación en máquina.
